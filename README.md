Sistema de calificaciones con arreglos en Python

Descripción
Este proyecto consiste en un programa desarrollado en Python que permite trabajar con las calificaciones de varios estudiantes utilizando arreglos y vectores.

Objetivo
Practicar el uso de arreglos, índices, ciclos y condiciones mediante un programa que calcula el promedio e identifica las calificaciones aprobadas y reprobadas.

Lenguaje utilizado
Python.

Funciones del programa
- Mostrar las calificaciones.
- Acceder a elementos mediante índices.
- Identificar aprobados y reprobados.
- Calcular el promedio del grupo.
- Mostrar la nota más alta y la más baja.
- Modificar una calificación y calcular el nuevo promedio.

Cómo ejecutar el programa
1. Tener Python instalado.
2. Descargar el archivo `sistema_calificaciones.py`.
3. Abrirlo con IDLE.
4. Ejecutar el programa y seguir las instrucciones.
